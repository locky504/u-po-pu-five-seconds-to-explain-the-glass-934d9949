A Node 22 program that writes the one sentence a house cat would say in the five seconds after sweeping a glass off the table — at most 200 characters, in the cat's own voice, no apology and no confession — to `/output/entry.txt`. The cat's defence: the glass had parked itself in the sunbeam and was throwing glare into the cat's eyes all morning, so one paw-nudge was pest control, and gravity did the actual dropping.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
